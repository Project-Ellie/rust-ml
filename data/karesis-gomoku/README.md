# karesis-gomoku/ — HuggingFace Karesis/Gomoku

26,378 labelled positions (875 games) generated by the WinePy
alpha-beta engine on 15×15 freestyle boards. The only Gomoku dataset
on HuggingFace with a clear, permissive license as of 2026-09-20.

- Source: https://huggingface.co/datasets/Karesis/Gomoku (DOI:
  10.57967/hf/4816)
- License: **MIT** (redistribution permitted with attribution)
- Downloaded 2026-09-20; `files/` is **git-ignored** to keep the repo
  lean (regenerate with `fetch.sh`).

## Content (`files/`)

| File | Shape | Meaning |
|---|---|---|
| `board_states.npy` | (26378, 15, 15) int8 | board before the move (values −1/0/1) |
| `next_moves_coords.npy` | (26378, 2) int64 | the engine's chosen move (row, col) |
| `next_moves_players.npy` | (26378,) int64 | the player to move (−1 / 1) |
| `DATASET-README.md` | — | the upstream dataset card |

Verified on download: shapes and dtypes as above; `board_states[0]`
has one stone with label `(7, 8)` for player `−1`.

## Fit

Supervised pretraining supplement (ch. 14 §5.3, phase 0). Small but
clean and permissively licensed; the label semantics (engine's move
as policy target) make it a behavior-cloning set — §5.4 item 4
(weak-label echo) applies.
